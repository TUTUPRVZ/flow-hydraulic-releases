# Flow | Гидравлическая схема

Публичная страница загрузки отдельного приложения Flow для построения и
гидравлического расчёта тепловых сетей.

Приложение открывает и сохраняет проекты `.flow`. Совместимость проектов,
созданных в Flow 0.5.0, сохранена и проверяется автоматическими тестами.

Манифест автоматического обновления:
[`latest.stable.json`](https://raw.githubusercontent.com/TUTUPRVZ/flow-hydraulic-releases/main/latest.stable.json).


В этом публичном репозитории находятся только файлы выпуска. Исходный код
хранится отдельно в закрытом репозитории.
