# Flow | Гидравлическая схема

## Установка для Windows x64

1. [Скачайте Flow Launcher](https://github.com/TUTUPRVZ/Flow-updates/releases/latest) и установите его.
2. В каталоге выберите «Гидравлическая схема» и нажмите «Установить».
3. Для обновления сохраните открытые проекты, закройте программу и нажмите «Обновить» в Launcher.

Установленную программу можно запускать через Launcher, меню «Пуск» или файл .flow. Удаление доступно в настройках приложений Windows.

## Версия 1.1.3

Launcher скачивает служебный установщик и проверяет SHA-256 перед запуском. Обновление необязательное. Установщик без цифровой подписи. Формат проекта — .flow 2.0. Перед сохранением проекта, созданного до 1.1.0, оставьте копию исходного файла.
